## Data and dependency contract

- Inputs and truth classes: block-scoped protocol reads from the injected
  client; optional indexed/editorial context from PND providers; artist copy
  from a normalized manifest.
- Read owner: the shared direct provider owns bounded current-state reads;
  PND/Postgres owns stored history and discovery.
- Write owner: the shared provider prepares declarative writes; wagmi submits
  them in each assembly.
- Freshness and finality: visible mutable state refreshes no tighter than 12
  seconds, validation no tighter than 30 seconds, and price is requoted at the
  latest block immediately before submission.
- External services: injected RPC only for core behavior; PND enrichment is
  optional and must be blockable.
- Request-time RPC effect: one release validation set, one bounded state
  multicall, one immediate pre-write quote, and visible paged token reads.
  No history scan, wallet enumeration, or full-grid URI fan-out.
- Worker or indexer effect: none.
- Database and migration effect: none.
- Storage and recurring-cost estimate: $0.

## Design

The shared provider remains the sole protocol adapter. `@pin/surface-react`
owns async state and refresh semantics. PND and the artist template only map
the resulting typed state into their visual systems and wallet libraries.

Generic fixed-price support must validate that the configured minter points
back to the collection. Homage remains an explicit adapter with its own quote,
eligibility, selection, and transaction behavior. Unsupported custom minters
disable writes with a useful message.

Token previews remain paged and visible-only. A heavy or failed `tokenURI`
becomes a typed reduced state; renderer assembly may still produce HTML when
the required work inputs are available. No card silently swaps in unrelated or
dummy media.

## Acceptance scenarios

- Sequential fixed price: PND and artist adapters produce identical lifecycle,
  price, target, args, value, referral, reveal, and error recovery.
- Scheduled, ended, collection-capped, minter-capped, gas-only, dynamic-price,
  allowlist, wallet-cap, changed-primary-minter, and RPC-failure states fail
  closed consistently.
- Homage uses only its explicit adapter; the generic path reports unsupported.
- The artist template renders a representative live sequential token through
  its canonical renderer path, or shows the exact typed reduced reason.
- PND endpoints blocked: core template release, price, mint preparation,
  explorer links, and supported rendering continue working.
- PND provider outage: PND retains the current release action when the direct
  provider is healthy; optional history/editorial context degrades separately.
- Desktop and 390px checks pass on the PR preview and live-data local artist
  template with no broken images or page-level overflow.
- RPC call counts and refresh intervals remain inside this packet's bounded
  contract and add no recurring infrastructure cost.
