## Scope

### Owned

- Create `@pin/release-spec` with normalized v1 types, validation,
  canonicalization, digest and EIP-712 payload helpers, capability identifiers,
  and artist-site declaration types.
- Create `@pin/surface-kit` with typed provider results, capability
  negotiation, pure lifecycle/quote/referral/error/reveal behavior, prepared
  transactions, adapter contracts, and the single render implementation.
- Create the minimal headless `@pin/surface-react` state boundary required for
  PND and the template to consume the same kernel.
- Move PND to the shared packages while retaining Postgres history, editorial,
  prepared-media, and route composition in `apps/web`.
- Move the artist template to workspace package dependencies and delete its
  vendored protocol/render behavior.
- Add sequential fixed-price and explicit Homage custom-adapter fixtures.

- Public npm publication or standalone repository synchronization, which
  occurs only after W1.3 parity and PND-offline gates pass.
- New collector-facing page layouts, owned by W2.2.
- Studio export, deployment, domain, and declaration workflows, owned by W3.
- Portable feeds, embeds, and launch packs, owned by W4.
- Production indexer cutover, owned by W0.2.

## Data and dependency contract

- Inputs and truth classes: protocol state from injected EVM clients; artist
  declaration from normalized manifests; indexed history and PND editorial
  context from optional, separately typed providers.
- Read owner: the kit owns bounded current-state reads through an injected
  client; PND keeps stored browse/history reads in Postgres.
- Write owner: prepared transactions are declarative; wallet libraries submit
  them in consuming assemblies.
- Freshness and finality: mutable state is block-scoped and requoted before a
  write; history providers retain coverage and finality evidence.
- External services: none required by the package. RPC, history, media, and
  identity providers are injected.
- Request-time RPC effect: bounded collection/minter/renderer reads only; no
  history scans, wallet enumeration, or token-grid URI fan-out.
- Worker/indexer effect: none.
- Database/migration effect: none.
- Storage and recurring cost: $0. Packages use the existing repository, CI,
  and consumer-provided transports.

## Design

The dependency direction is one way:

```text
@pin/abi + @pin/addresses
              -> @pin/release-spec
              -> @pin/surface-kit
              -> @pin/surface-react
              -> PND web | artist template
```

Extraction proceeds in compilable slices:

1. release specification, normalization, digest, and capability contracts;
2. provider result and adapter contracts;
3. pure state, quote, transaction, reveal, and error functions;
4. render assembly moved from the app into the kit;
5. PND adapters and imports;
6. template adapters and removal of vendored copies;
7. shared React state primitives;
8. parity and PND-offline enforcement.

Unknown required capabilities disable the primary action. Optional provider
failure removes only the enhancement and returns a typed reduced state. Raw
canonical media and artist copy remain usable without PND services.

## Acceptance scenarios

- Sequential fixed-price Surface: identical lifecycle, quote, target, calldata,
  value, referral, receipt, and reveal in both assemblies.
- Gas-only, scheduled, ended, capped, sold-out, dynamic-price, allowlist, and
  wallet-cap states remain distinct and deterministic.
- Homage uses an explicit pooled/custom-minter adapter; the generic adapter
  must report it unsupported.
- Renderer with and without preview support yields a typed result rather than
  a broken preview.
- Image, video, HTML, loading, unavailable, and failed media states remain
  distinct.
- Unknown optional capabilities reduce context; unknown required capabilities
  disable writes.
- With every PND hostname blocked, the artist template can still validate,
  render, quote, mint, recover errors, reveal, and link to configurable
  explorers.
- The representative live Homage and abstracts releases pass desktop and 390px
  review without request-time history scans.
